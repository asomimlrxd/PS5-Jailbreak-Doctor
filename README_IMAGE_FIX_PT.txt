Correção das imagens dos READMEs

- As referências das imagens usam caminhos relativos explícitos (./docs/images/...).
- O banner e o diagrama de fluxo têm também versões PNG para maior compatibilidade de renderização.
- Os ficheiros docs/images/banner.png, docs/images/data-flow.png, docs/images/diagnostic-results.png e docs/images/connection-panel.png estão incluídos neste pacote.
- Ao publicar no GitHub, é necessário enviar/commit também a pasta docs/images; alterar o README sem enviar estes ficheiros não fará as imagens aparecerem.
